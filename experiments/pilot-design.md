# Pilot 实验设计：三元组门控 vs 单量门控（最小可判读版）

> 课题：证书门控-多层扰动度量 ｜ 阶段：实验侧启动（Phase 0）
> 设计日期：2026-10-22 ｜ 状态：smoke 管线验证通过（phase 0），**未出任何结论**
> 文献依据：brief.md（三篇全文交叉，2026-10-21 夜扫）——本设计只做操作化，不重新论证文献

## 0. 判决对象与完备性论证

**假设 H**：持续学习的结构决策（并入共享结构 / 隔离 / 扩展容量 / 重算全局结构）的触发量
应为三元组——表征层 CKA 稳定/可塑性 + 更新层谱干涉界 ||ΔW||₂·||J||_* + 几何层锚泄漏 β——
任一单量不足。

**完备性论证（立项 taste 雷：组合必须过必要性论证，不能说"三层比一层好"）**：
三层不是"更多特征"，而是三条独立失效通道，缺一层就漏一种失效模式：

| 层 | 失效通道 | 缺了它会漏什么 |
|---|---|---|
| 表征层 CKA 漂移 d=1−S | 表征几何不可共存 | 更新量正常但表征空间已被新任务改写，旧任务决策面随之漂移——纯梯度量看不见 |
| 更新层谱干涉界 B | 最坏情况一阶旧任务损失上界 | 表征稳定但更新恰好打在旧任务高灵敏方向——小幅更新、大幅干涉，纯表征量看不见 |
| 几何层锚泄漏 β | 更新子空间与锚梯度的方向共线 | 前两者量级都小，但锚梯度能量落在更新子空间内——方向性结构泄漏，纯范数量看不见 |

**驳倒方式（预注册）**：三量跨任务两两秩相关 |ρ|>0.9 → 三元组退化为单量 → H 驳倒（§7 F1）。

## 1. 臂设置（同一协议，五臂同架构同参数量）

| 臂 | 触发通道 | 说明 |
|---|---|---|
| A0 baseline | 无 | 不门控，全部并入 |
| A1 cka-only | z(d) | 仅表征层 |
| A2 spectral-only | z(B) | 仅更新层 |
| A3 beta-only | z(β) | 仅几何层 |
| A4 triplet | max(z(d),z(B),z(β)) | 三元组 |

所有臂都计算全部三个量（退化检查需要），只是进入告警的通道不同；数据、初始化、
训练协议、参数量完全一致（slots 构造保证，§4）。

## 2. 门控语义（rollback-retrain，最小可实现且触发器因果）

任务 i 到达 → 默认在共享 trunk 试训练 → 任务边界计算三量 → 告警则回滚 trunk
（参数快照恢复）→ 打开隔离槽在专用模块上重训任务 i → 记 action=isolate；否则
action=merge。槽位耗尽 → 强制 merge（记 forced）。hysteresis：上一动作 isolate
且 max z ∈ [τ−0.3, τ] → 维持 isolate（抖动抑制，override 记入日志）。

τ_hi=2.0（z 分数，running μ/σ）。门控从**第 3 个任务起**：第 1 任务无先验、
第 2 任务 z 样本<2 记为 0 不告警（两者默认并入）。

触发器因果性要求：三量全部在决策时点可计算（锚集+参数快照），不依赖训练后结果——
避免"用遗忘当触发器"的循环论证。

## 3. 触发量操作化定义（决策时点全部可计算）

记号：θ_{i-1}=任务 i 训练前状态，ΔW=θ_i−θ_{i-1}；每任务存锚集 A_r（训练集前 m 条）
+ 测试集（遗忘评估）。

- **表征层**：S_i = linCKA(Φ_{i-1}(A_{i-1}), Φ_i(A_{i-1}))，Φ 取共享 trunk 隐层；
  漂移 d_i = 1 − S_i。特征在任务边界缓存（O(T·m·width)）。
- **更新层**：J_r = 锚任务 r 在 θ_{i-1} 的逐样本梯度矩阵（m×P，torch.func vmap）；
  B_i = ||ΔW||₂ · max_r ||J_r||_*（核范数 SVD）。一阶旧任务损失上界通道。
- **几何层**：s_i = span{ΔW_{i-1}, ΔW_i}（QR 正交基，ΔW 取试训练量——无论最终
  动作，量的是"若并入会怎样"）；β_i = max_r ||Qᵀ J_rᵀ||_F / ||J_r||_F，即锚梯度
  能量落入最近两个更新方向张成子空间的比例。

**数据访问声明（claim 一致性自检）**：三量均依赖存储的锚集与锚梯度矩阵（每任务 m 条
样本 + 梯度缓存）。这是显式记忆访问，论文不得声称 rehearsal-free；所有臂同记忆预算。

## 4. 数据与模型

- **数据（合成序列，Phase 0/1/3）**：T 个任务，每任务 k=10 类（smoke/pilot 同协议，
  仅 T/宽度/步数变）；任务 t 类中心 = 基中心经随机正交旋转 × 漂移缩放 (1+ρ·t/(T−1))，
  各向同性噪声 1.0，d=30；训练/测试/锚集规模按 phase 配置；固定 seed 可复现。
  难度校准记录：k=4/noise=0.5 时准确率饱和 1.0、遗忘恒 0——对比区不存在，
  baseline 必须有非零遗忘，度量才有意义。旋转制造表征冲突，漂移制造可塑性压力。
- **数据（Phase 2 升级）**：Split-CIFAR10（5 任务 × 2 类，3072 维输入），
  同 slots 架构（可换小 CNN trunk）。
- **模型**：MLP trunk（两层，宽度 smoke=64 / pilot=256）+ per-task 线性头；
  K=4 槽位（trunk0=共享并入目标，1..3=隔离池），五臂总参数量相同（构造保证，
  metrics.json 记录实际值）。

## 5. 度量（落盘 results/metrics.json）

每任务记录：三量原值、z 分数、门控动作（merge/isolate/forced/hysteresis-override）、
训练/测试 acc、全部已见任务 acc（→遗忘）、参数计数、各计算耗时（J/SVD/CKA/训练）。
序列级：平均遗忘 F̄（主判据）、最终平均 acc、动作统计、action-switch rate（抖动）、
三量两两 Spearman ρ（退化检查）、触发计算/训练耗时比。

## 6. 判读标准（预注册）

- **主判据**：F̄(A4) < F̄(A1/A2/A3) 各自；配对种子 bootstrap 95% CI 不含 0；
  且 ΔF̄ ≥ 5 分（相对单臂均值）。
- **次判据**：①F̄(A4) < F̄(A0)（门控相对不门控有效）；②长序列增益单调放大：
  T=50 vs T=10 的 ΔF̄ 差距（≥2 个序列长度点验证"长序列才显著"预测）。
- 完成判据是真实产物：metrics.json 落盘 + 命令可复现 + commit 记录，不是"跑过代码"。

## 7. 失败条件（任一触发即停或改向，全部预注册）

- **F1 退化**：任一臂内三量两两 |ρ|>0.9 → 三元组=单量，H 驳倒；停止放大规模，写负结果。
- **F2 抖动**：任一臂 action-switch rate >30%（hysteresis 已开）→ 阈值规则失效，重设计后再判。
- **F3 无增益**：等参数量下三元组不显著优于任一单量 → pilot 尺度 H 未获支持；
  升级长序列 phase 再判，仍无则驳倒。
- **F4 工程**：NaN / CKA 未定义 / SVD 失败 → 修管线，记 FAILURE-PATTERNS。
- **F5 成本**：触发计算（J+SVD+CKA）> 单任务训练耗时 20% → 可扩展性缺陷，必须报告
  （taste 雷：评审把计算成本当独立缺陷打）。
