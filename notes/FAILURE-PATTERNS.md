# 失败模式库（FAILURE-PATTERNS）

> 记跑通过程中真实触发的失败/工程模式（预注册 F1-F5 及工程坑），
> 每条带：现象 / 根因（已验证或假设）/ 处置 / 教训。

## F2 抖动：hysteresis 在趋势性触发量上失效（2026-10-22，Phase 1 pilot 触发）
- 现象：spectral/triplet 臂 action-switch rate 0.49(mean)/0.67(max) > 30% 阈值；
  动作序列在 merge/isolate 间逐任务振荡。
- 根因（假设，待下单元验证）：bound = ||ΔW||·max_r||J_r||_* 随任务序号单调增长
  （seed0 量级 27→581），RunningZ 用全历史均值/方差 → 均值滞后于趋势 → 晚期任务
  z 持续 >τ、早期 z<τ → 边界附近来回穿越。hysteresis band=0.3 太窄兜不住。
- 处置：按预注册 F2"重设计后再判"——下一单元候选修法：①触发量去趋势（减任务序号
  线性项）再算 z；②提高 τ；③动作持续期平滑（连续 k 个边界告警才切）。验收：switch<0.3
  且 F 不劣化于 pilot（0.0331）。
- 教训：对非平稳（有趋势）序列做 running z 告警，滞后是结构性的——告警规则必须
  对触发量的平稳性有假设并检验（F1 检查里原始 vs 去趋势相关性的巨大差异就是同一现象
  的另一个切面）。

## F5 成本：触发计算超训练 20%（2026-10-22，Phase 1 pilot 触发，必须报告）
- 现象：cost_ratio ~0.35（width 64）；width 256 时 1.5+（SVD 1.78s vs 训练 1.4s）。
- 根因：spectral_bound 对每个锚任务做 m×P 矩阵的 SVD（O(m²P)）；anchor_jacobians
  每任务边界覆盖全部 i 个锚任务 → 总成本 ~O(T²·m²P)，训练 ~O(T·steps)。
- 处置：如实报告为可扩展性缺陷（评审会当独立缺陷打，taste 雷）。候选优化留给后续：
  锚任务抽样 / SVD 换 randomized / 缓存 J（任务边界间不重算）。
- 教训：P（参数量）进 SVD 成本 → width 翻倍成本涨 ~4×；门控宣称要附成本随
  T/P/m 的实测曲线，不能只报一个比值。

## 难度饱和：宽容量压掉遗忘（2026-10-22，Phase 1 首跑触发）
- 现象：pilot width 256 首跑 baseline F=0.0052（smoke width 64 曾 0.0375）；
  drift=1.0 扫描更低（0.0030）；spectral 从不告警（门控路径空转）。
- 根因：MLP trunk 容量足够同时保持 10 个旋转任务的决策面 → 对比区不存在。
- 处置：校准扫描定 width 64（与 smoke 同协议），F=0.0534 回到非零对比区；
  width 256 记否决配置（cost 还顺带 1.5+）。
- 教训：持续学习合成基准的"难度"由容量×冲突强度共同决定——放宽度前必须先验证
  baseline 遗忘仍在非零区，否则门控实验空转。

## 图像分布触发惰性 + 尖峰误触发：门控有效性不跨分布（2026-10-22，Phase 2 触发）
- 现象：Split-CIFAR10 τ=2.0 下 27 个决策点仅 6 次告警（bound 2 / beta 4），drift 通道 0/27；
  门控效果符号翻转（seed1 F −40% 获益、seed2 +34% 反噬）；spectral 臂均 F 反超 baseline
  （0.1190 vs 0.1121）。
- 根因（假设）：图像任务上 bound/beta 尖峰多为任务难度波动而非结构冲突（τ=2.0 无法区分）；
  drift 恒负因 MLP trunk 表征随序列训练收敛变稳；隔离槽 100 步×2000 样本在图像上欠拟合 →
  回滚+重训的收益被欠拟合吃掉（合成任务易学所以 pilot 上有效）。
- 处置：报告为分布敏感性负结果（论文负面骨架）；下一单元候选：τ 分布校准（只能作敏感性
  分析报告，防事后调参）/ 尖峰持续期确认（连续边界告警才切）/ 隔离槽步数随任务规模放大。
- 教训：触发规则跨分布迁移时，告警率必须按分布重新校准；门控有效性本身可能是分布相关的，
  合成基准的显著性不能外推到图像。

## 高维输入触发成本爆炸（2026-10-22，Phase 2 触发，F5 加重）
- 现象：CIFAR（d=3072，P=3.4M）稳态 cost_ratio ≈ 11×（pilot 合成 0.35×，P=31K）；
  baseline 臂首调 21.98×（首次 cuSOLVER/分配器开销，3 种子一致，预热块未覆盖，根因未定位）。
- 根因：J 为 m×P（64×3.4M=873MB/锚任务）、svdvals O(m²P)；P 比合成大 110×。
- 处置：如实报告（taste 雷②）；候选优化：锚任务子采样 / randomized SVD / 缓存 J 跨边界复用。
- 教训：门控三量在原始像素高维输入上成本不可接受——论文方案必须附"输入维度→成本"曲线
  或适配层（CNN 特征/降维后再门控）。
