### Verdict：**高契合度——三条用户兴趣线均有对应，且三条线在本课题 converging**

### 3.1 用户兴趣线对齐

| 兴趣线 | 本课题对应 | 契合度 |
|---|---|---|

| **持续学习 / 结构干预时机** | 这是本课题的直接定位。`brief.md`：触发量应是多层扰动度量三元组，决定「何时长单元/剪枝/重连/重置」 | **直接对齐**——课题本身就是这条兴趣线的实验载体 |
| **表征漂移** | 2609.36081（scaffold =「往哪变」的几何约束）+ 本课题（「何时变」的触发证书）=「何时+往哪」的结构干预决策完整闭环 | **高**——两条线在本课题 converge，不是竞争 |

| 既有课题 | 与本课题关系 | 冲突/互补 |
|---|---|---|
| **快权重门控-时间尺度可塑性**（stopped） | 不同机制族（fast weight 滤波 vs 结构门控），H1 均被证伪。两课题共享「结构干预时机」动机但路径不同 | **互补**——负结果互相支撑「时机决策是难题」而非竞争 |
| **Agent 记忆线**（未立项，信号池中） | REM/MCCL 的「何时注入」与证书门控的「何时干预结构」同构——立项时可共享「struggle gate → 证书门控」的机制族论证 | **互补**——本课题若发表，可为 Agent 记忆线提供「结构层决策」的对照锚点 |

### 3.3 课题组合的叙事完整性

三条用户兴趣线在本课题 converging 的具体表现：

```
表征漂移方向（2609.36081 scaffold）
        ↓ 耦合点：「何时变结构」的决策
证书门控（本课题，多层度量触发）
        ↓ 同构映射

本课题若作为负结果发表，叙事角色是**边界条件贡献**——界定了多层门控在合成数据上有效、在图像数据上失效的条件，为表征漂移线和 Agent 记忆线提供了「失败模式参照」。

### 5.2 成文定位建议（供路径 A 参考）

若路径 A 获批，建议论文框架：

```
标题方向：Boundary Conditions for Multivariate Gating in Continual Learning
          （或：When Multivariate Gating Adds No Value: A Preregistered Negative Result）

核心论点：
  1. 多层门控（CKA/谱界/泄漏项三元组）在合成数据上有效（bound 单通道 −41%），
     但在图像分布上失效（门控反而劣化）——分布敏感是第一条边界条件。
  2. 槽位饱和是长序列失效的结构性原因：门控容量假设稀疏告警，T=50 下
     3 槽在 task 4-8 耗尽，中晚期强制归并抵消全部隔离收益。
  3. 触发计算成本随 T 超线性（实测 ~T²·m²P vs 训练 ~T），可扩展性为独立限制。

叙事锚点：
