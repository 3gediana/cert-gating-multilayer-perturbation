## F3 结构检查

- triplet 与 spectral 动作序列逐种子一致：{0: True, 1: True, 2: True, 3: True, 4: True} → 全部一致
- 从不告警臂（isolate 总数=0）：{'cka': True, 'beta': True}
- **槽位饱和结构（triplet，T=50）**：每种子 slots_used / isolate 任务 / 首次 forced 任务 / 带告警被强制 merge 次数——
  - seed0: slots=4 isolate@[4, 5, 6] first_forced=task7 forced_with_alarm=9
  - seed1: slots=4 isolate@[4, 5, 6] first_forced=task10 forced_with_alarm=3
  - seed2: slots=4 isolate@[4, 5, 6] first_forced=task9 forced_with_alarm=8
  - seed3: slots=4 isolate@[4, 5, 6] first_forced=task9 forced_with_alarm=10
  - seed4: slots=4 isolate@[6, 7, 8] first_forced=task27 forced_with_alarm=1
  → 3 个 isolate 槽在序列早期（task 4-8）即耗尽，中晚期告警全部落为 forced merge：T=50 下门控运行在**槽位饱和区**（机制容量假设稀疏告警，长序列不成立）——三元组无增量的结构性解释之一。
